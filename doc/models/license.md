
# License

*This model accepts additional fields of type Any.*

## Structure

`License`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `id` | `uuid\|str` | Optional | Unique license ID. |
| `name` | `str` | Optional | User-provided name for the license. |
| `expiration` | `datetime` | Optional | Expiration timestamp, inherited from the organization's licensing terms. Absent when the organization has no licensing terms configured. ISO-8601. |
| `memory` | `str` | Optional | Memory reserved for license. |
| `environment_fingerprint` | `str` | Optional | Environment fingerprint generated by private infrastructure. |
| `additional_properties` | `Dict[str, Any]` | Optional | - |

## Example

```python
import dateutil.parser
import jsonpickle

from openapispecforclickhousecloud.models.license import License

license = License(
    id='00001e2e-0000-0000-0000-000000000000',
    name='name6',
    expiration=dateutil.parser.parse('2016-03-13T12:52:32.123Z'),
    memory='memory6',
    environment_fingerprint='environmentFingerprint2',
    additional_properties={
        'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
    }
)
```
